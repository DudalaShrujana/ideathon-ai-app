# 🚀 Ideathon AI Innovation Hub

A production-ready, serverless AI-powered web application built with Streamlit, Google Cloud Run, Firebase, and Gemini API for enterprise ideation and strategic planning.

## ✨ Features & Architecture

* **Multi-Turn Gemini Integration:** Leverages Google's latest Gemini models (`gemini-2.5-flash` and `gemini-2.5-pro`) for rich, context-aware business strategy generation.
* **Cloud Run Deployment:** Fully containerized and deployed serverlessly on Google Cloud Run with automatic scaling.
* **Firebase & Firestore:** Integrates Firebase Admin and user-isolated Firestore document storage to persistently save generated reports and user sessions.
* **Google Cloud Secret Manager:** Implements secure secrets handling patterns for robust enterprise configuration.
* **Interactive Tooling:** Includes quick-prompt templates (Growth Strategy, Risk Assessment, Product Roadmap) and one-click report downloads.

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit (Python)
* **AI Engine:** Google GenAI SDK & Vertex AI (Gemini API)
* **Backend & Storage:** Firebase Admin, Cloud Firestore
* **Security & Deployment:** Google Cloud Secret Manager, Cloud Run, Docker
